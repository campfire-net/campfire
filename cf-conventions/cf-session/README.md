# cf-conventions/cf-session

Package `cf-session` provides session lifecycle management and lazy-mint
per-worker grant issuance for campfire swarm orchestration.

## Purpose

The old `cfs1_` token embedded a shared private key, giving every worker the
same identity and destroying per-worker attribution. `cf-session` replaces this
with a lazy-mint model: the orchestrator holds its own key, issues each worker a
unique Ed25519 keypair and a scoped delegation grant, and closes the session
when work is done.

Workers are isolated in a "jail" directory — their key files are written to a
`0700` directory with `0600` file permissions, inaccessible to other processes.

## Public Surface

| Symbol | Description |
|--------|-------------|
| `CapabilityTemplate` | Convention + op-glob + TTL for worker grants |
| `SessionOpenPayload` | Payload emitted with `session:open` tag |
| `SessionClosePayload` | Payload emitted with `session:close` tag |
| `WorkerIdentity` | Ed25519 keypair for a single worker |
| `GenerateWorkerIdentity()` | Create a fresh worker keypair |
| `MaterializeWorkerIdentity(jailPath, wid)` | Write worker key to jail dir |
| `LoadWorkerIdentity(jailPath)` | Load worker key from jail dir |

| `TagSessionOpen` | `"session:open"` (re-exported from cf-protocol) |
| `TagSessionClose` | `"session:close"` (re-exported from cf-protocol) |

## Session Lifecycle

```
1. Orchestrator: client.NewSession(ttl) → sess, sessionID
2. Orchestrator: OpenSession(sess, &SessionOpenPayload{Template: template})
3. Per worker:   GenerateWorkerIdentity() → wid
4. Orchestrator: IssueWorkerGrant(client, sessionID, wid.PublicKey, template)
5. Worker:       MaterializeWorkerIdentity(jailDir, wid)
6. Worker:       protocol.Init(jailDir) → works with scoped identity
7. Orchestrator: CloseSession(sess, &SessionClosePayload{})
   → coordination log eligible for compaction
```

## Token Format

`cfs2_` tokens embed real transport config (endpoint URL, transport type). They
are generated by `cf session create --ttl <duration>`. `cfs1_` tokens (which
embedded a raw private key) are rejected with a clear migration error — regenerate
any stored tokens with `cf session create`.
